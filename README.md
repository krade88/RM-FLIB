# RM-FLIB — roadmap до платформы уровня FLIB

Интерактивный учебный маршрут: от полного нуля до full-stack платформы для чтения и публикации ранобэ — такого же продукта, как [FogrestRead / FLIB](https://github.com/krade88/FLIB).

## Что внутри

- **13 этапов** — от терминала и Git до Laravel, Vue, Inertia, тестов, Docker и сборки продукта.
- **173 под-тем** — у каждой своя практика, чекпоинт и ресурсы.
- **439 ссылок** — документация, упражнения (Exercism, Frontend Mentor, TypeScript Exercises) и русскоязычные альтернативы.
- **Частые ошибки** — у каждой темы есть блок с типичными ловушками.
- **Интерактивный прогресс** — отметки тем сохраняются в `localStorage`.
- **Темп обучения** — 10/15/20/25 часов в неделю с пересчётом сроков.
- **Адаптивная вёрстка** и тёмная тема в стиле FLIB.

## Структура

```
RM-FLIB/
├── index.html          # разметка страницы
├── css/
│   └── styles.css      # оформление, адаптив, анимации
├── js/
│   ├── data.js         # 13 этапов и 173 тем: практика, чекпоинты, ресурсы
│   └── app.js          # рендер, прогресс, аккордеоны, темп, навигация
├── assets/
│   └── favicon.svg
└── README.md
```

## Запуск

Проект статический, сборка не нужна.

1. Откройте `index.html` в браузере.
2. Или запустите локальный сервер:

```bash
npx serve .
# или
python -m http.server 8080
```

## GitHub Pages

Репозиторий готов к публикации как статический сайт:

1. Settings → Pages.
2. Source: **Deploy from a branch**.
3. Branch: `main`, folder: `/` (root).

## Как редактировать

- **Контент** — `js/data.js`: этапы, темы, практика, чекпоинты, ссылки.
- **Логика** — `js/app.js`: прогресс, раскрытие тем, переключатель темпа.
- **Стили** — `css/styles.css`.
- **Разметка** — `index.html`.

Прогресс хранится только в браузере пользователя и не отправляется на сервер.
